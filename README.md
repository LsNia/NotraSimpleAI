# NOTRA

Музыкальный чат подбирает треки и альбомы под настроение, знакомит с жанрами и объясняет, как звучит музыка. У всех, кто входит по ключу, одна общая переписка.

## Локальный запуск

Понадобятся Python 3.11 или новее и ключ Gemini API. Ключ для модели можно получить в [Google AI Studio](https://aistudio.google.com/api-keys).

Выполните команды из корня проекта. На шаге с редактором заполните два поля в `.env`. В `ACCESS_KEY` задайте собственный ключ входа длиной 8–255 символов из латинских букв, цифр, дефиса и подчёркивания. В `GEMINI_API_KEY` вставьте ключ Google. Если файл уже существует, команда копирования его сохранит.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp -n .env.example .env
nano .env
.venv/bin/python -m uvicorn app.main:app --env-file .env --port 8010
```

Откройте [чат на localhost](http://127.0.0.1:8010) и введите значение `ACCESS_KEY`. После изменения настроек в `.env` перезапустите сервер.

## Устройство проекта

| Файл | Назначение |
| --- | --- |
| `app/main.py` | Приложение FastAPI, раздача страницы и маршруты чтения и отправки сообщений. |
| `app/auth.py` | Проверка ключа, выдача сессии и выход из неё. |
| `app/storage.py` | Доступ к SQLite. База создаётся автоматически в `data/pomol.sqlite3`. Путь можно задать через `DATABASE_PATH`. |
| `app/gemini.py` | Системный промпт музыкального чата и HTTP-клиент Gemini. Модель выбирается через `GEMINI_MODEL`. |
| `app/static/` | Одна HTML-страница, стили, JavaScript, фотография и шрифты. Сборка фронтенда не требуется. |
| `tests/test_chat.py` | Проверки авторизации, ограничений ввода, сбоев модели и сохранности переписки. |

Браузер отправляет ключ доступа в теле запроса при входе. Сервер сравнивает его через `compare_digest` и выдаёт случайный токен в cookie с атрибутами `HttpOnly` и `SameSite=Strict`. При работе по HTTPS добавляется `Secure`. В SQLite хранится HMAC токена. Сессия действует семь дней, выход отзывает её сразу, а смена ключа доступа аннулирует ранее выданные сессии.

SQLite позволяет хранить историю между запусками без отдельного сервиса. Вопрос и готовый ответ записываются вместе, со своим временем в UTC для каждой реплики. Браузер показывает дату и время в часовом поясе читателя. При ошибке вопрос возвращается в поле ввода. Идентификатор отправки защищает от повторной записи, если ответ сервера потерялся по пути к браузеру.

Gemini получает системный промпт, текущий вопрос и шесть последних пар реплик. Ключ провайдера используется только сервером. [Документация Gemini API](https://ai.google.dev/api/generate-content)

## Проверка

```sh
.venv/bin/python -m unittest discover -s tests
```

Тесты создают временную базу и подставляют ответы Gemini на уровне HTTP. Ключ провайдера для них не нужен.

## Что можно доработать

- Показывать рекомендации по мере генерации ответа.
- Загружать старые сообщения при прокрутке вверх, когда история вырастет.
- Ограничить частоту неудачных попыток входа при размещении чата в интернете.
